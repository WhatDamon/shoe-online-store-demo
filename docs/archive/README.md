## 关于本目录内的失效链接

`HANDOVER.md` 中残留 `C:/Users/Administrator/...` 形式的 Windows 绝对路径。**不要“修复”它们**：
那是当时开发流程确实耦合 Windows 工作树的证据，改写会篡改历史记录。

另有一处链接指向 `从最小后端到交易闭环-图解教学-2026-09-30.md`，该文档经核验从未存在。
它的**路径基准已随归档一并修正**（这是应当做的），但**不要为它新建目标文档**——
凭空补一份教学文档比留一条断链更有害。

唯一应当修复的是「文档移入本目录后因相对基准变化而失效的链接」。若将来再移动归档文件，
请用「解析相对链接并检查目标存在」的方式复验；但注意**目标存在不等于目标正确**
（例如 `./README.md` 会解析到本索引文件，而原意是仓库根目录的 README，
这类静默指向错误比断链更难发现）。
